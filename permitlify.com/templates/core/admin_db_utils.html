📦 Dropbox (durable backup target) {% if dbx_configured %} CONFIGURED {% else %} NOT CONFIGURED {% endif %}
Local ./backups/ files vanish on every redeploy because the container disk is ephemeral. Configure Dropbox below and every new backup is automatically uploaded to a folder in your Dropbox account — so the file survives any restart, redeploy, or local-disk wipe.
📘 One-time Dropbox setup (≈3 minutes)
  1. Go to dropbox.com/developers/apps and click Create app.
  2. Choose Scoped access → App folder (recommended — Dropbox sandboxes the app to /Apps/<your-app-name>/), name it e.g. Permitlify Backups.
  3. Open the Permissions tab and tick all of: files.content.write, files.content.read, files.metadata.read, files.metadata.write. Click Submit.
  4. Back on the Settings tab, copy the App key and App secret into the fields below.
  5. Generate a refresh token (one-time):
    • Fill in App key and App secret below first.
    • Click the 🔗 Open Dropbox authorize page button (appears once App key is filled in) and click Allow.
    • Copy the short authorization code Dropbox shows you, paste it into the Authorization code box that appears below, and click Exchange for refresh token.
    • The Refresh token field fills in automatically. ⚠️ Do NOT paste the short auth code directly into the Refresh token field — that's the most common mistake and causes invalid_grant: refresh token is malformed.
  6. Click Save & verify connection — a real test file is uploaded then deleted to confirm write access. Refresh tokens never expire, so this is a one-time setup.
